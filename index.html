Enter two names to play. We'll show the matching letters, the count, and each elimination round.

How do you play?
  1. Write down both names and cancel matching letters one-for-one.
  2. Count all the letters left in both names.
  3. Count that number around F-L-A-M-E-S and scratch out the letter you land on.
  4. Start counting again from the next letter. Keep going until one letter survives!

# FLAMES Playground

A nostalgic, notebook-inspired take on the classic FLAMES name-counting game.

## Run locally

Open `index.html` in any modern web browser. The site is a standalone HTML file and does not require a build step, dependencies, or a backend.

## Deploy with GitHub Pages

1. Create a public GitHub repository named `FLAMES-Playground`.
2. Add `index.html` and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. After the deployment finishes, the site will be available at `https://YOUR-GITHUB-USERNAME.github.io/FLAMES-Playground/`.
